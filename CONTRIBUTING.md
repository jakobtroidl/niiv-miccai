# Contributing to NIIV

Thank you for considering contributing to NIIV! We welcome contributions from the community.

## How to Contribute

### Reporting Issues

If you encounter a bug or have a feature request:
1. Check if the issue already exists in the [Issues](https://github.com/jakobtroidl/niiv-miccai/issues) section
2. If not, create a new issue with a clear description
3. Include relevant details: OS, Python version, error messages, and steps to reproduce

### Contributing Code

1. **Fork the repository** on GitHub

2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/niiv-miccai.git
   cd niiv-miccai
   ```

3. **Create a new branch** for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make your changes** following our coding standards

5. **Test your changes** to ensure they work as expected

6. **Commit your changes** with clear, descriptive commit messages:
   ```bash
   git add .
   git commit -m "Add feature: brief description"
   ```

7. **Push to your fork**:
   ```bash
   git push origin feature/your-feature-name
   ```

8. **Create a Pull Request** on GitHub with a clear description of your changes

## Code Style Guidelines

- Follow [PEP 8](https://pep8.org/) style guidelines for Python code
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions focused on a single task
- Add docstrings for public classes and functions

## Testing

- Test your changes on multiple datasets if possible
- Ensure existing functionality is not broken
- Include unit tests for new features when applicable

## Documentation

- Update the README.md if your changes affect usage
- Add docstrings to new functions and classes
- Update configuration examples if needed

## Contact

For questions or discussions, please:
- Open an issue on GitHub
- Contact the maintainers at jakob_troidl@fas.harvard.edu

We appreciate your contributions to making NIIV better!
