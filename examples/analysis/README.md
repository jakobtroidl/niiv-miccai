# Analysis Notebooks

This directory contains Jupyter notebooks used for exploration and analysis during development.

## Contents

- **abs-image-diff.ipynb** - Image difference analysis
- **fft.ipynb** - Fourier transform analysis
- **gradient.ipynb** - Gradient analysis
- **ista.ipynb** - ISTA algorithm exploration
- **mse-fourier.ipynb** - MSE and Fourier space analysis
- **png2tensor.ipynb** - Image to tensor conversion utilities
- **tensor2png.ipynb** - Tensor to image conversion utilities
- **plot_denoise.ipynb** - Denoising experiments
- **plot_denoise_wavelet.ipynb** - Wavelet-based denoising
- **plot_nonlocal_means.ipynb** - Non-local means denoising

These notebooks are provided as-is for reference and may require adjustments to run with your data.
